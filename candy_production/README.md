# Candy Production Forecasting

## Forecasting Monthly Production with Google BigQuery ML

This project develops a time-series model to forecast candy production and support inventory and capacity planning.

The project covers data validation, trend and seasonality analysis, stationarity testing, model development, residual evaluation, and business recommendations.

An **ARIMA_PLUS** model was built using Google BigQuery ML to generate a **24-month forecast** with 95% confidence intervals.

The analysis identified a recurring 12-month seasonal pattern, with production peaks in Q4 and lower levels around April and May.

The forecast can support production scheduling, inventory preparation, and workforce planning.

**Tools:** Python, Pandas, Matplotlib, SQL, Google BigQuery ML
