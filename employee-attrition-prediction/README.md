# Employee Attrition Prediction

## Predicting Employee Turnover with Google BigQuery ML

This project develops an employee attrition early warning model to help HR identify employees who may leave the company and prioritize timely retention actions.

The project covers the complete analytics workflow, including data preprocessing, exploratory data analysis, machine learning, model evaluation, risk segmentation, and business recommendations.

Two classification models were trained and compared using **Google BigQuery ML**:

* Logistic Regression
* Boosted Tree Classifier
