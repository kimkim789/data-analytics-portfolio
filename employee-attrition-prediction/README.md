# Employee Attrition Prediction

## Predicting Employee Turnover with Google BigQuery ML

This project develops an employee attrition early warning model to help HR identify employees who may leave and prioritize retention actions.

The project covers data preprocessing, exploratory data analysis, model development, evaluation, risk segmentation, and business recommendations.

Two classification models were trained and compared using **Google BigQuery ML**:

- Logistic Regression
- Boosted Tree Classifier

Logistic Regression was selected, achieving a **ROC-AUC of 0.84** and **77.3% recall** on more than 74,000 employee records.

Key attrition signals included entry-level roles, poor work-life balance, and limited remote-work flexibility.

> **Tools:** Python, Pandas, Matplotlib, SQL, Google BigQuery ML.
