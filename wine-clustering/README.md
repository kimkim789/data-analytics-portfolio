# Wine Product Segmentation

## Product Segmentation with K-Means and PCA

This project applies unsupervised machine learning to segment wine products based on their chemical characteristics.

The project covers data preprocessing, feature scaling, exploratory data analysis, PCA visualization, K-Means clustering, model evaluation, and segment profiling.

Two clustering solutions were compared using **Google BigQuery ML**:

- K-Means with K = 3
- K-Means with K = 4

The three-cluster solution was selected based on clustering metrics and business interpretability.

The clusters were translated into **premium, mass-market, and niche/blending** product segments to support portfolio, pricing, and distribution strategies.

> **Tools:** Python, Pandas, Matplotlib, Scikit-learn, SQL, Google BigQuery ML.
